# WANTED | Subasta Inversa Global 🚀

**WANTED** es la plataforma disruptiva de comercio inteligente donde la oferta persigue a la demanda. A diferencia de los marketplaces tradicionales, aquí los **compradores publican lo que buscan** y los **vendedores compiten** en tiempo real por ofrecer el precio más bajo.

## 🎯 Características Principales
* **Conexión Global:** Encuentra productos específicos desde cualquier parte del mundo.
* **Subasta Inversa:** Obtén el mejor precio posible gracias a la competencia directa entre proveedores.
* **Categorías Calientes:** Especializados en **Teléfonos Inteligentes**, **Repuestos Automotrices**, **PlayStation 5**, **Hardware PC** y **Relojes Inteligentes**.
* **Seguridad Garantizada:** Filtramos el spam mediante una tasa de conexión mínima para asegurar transacciones reales.

## 🛠️ Tecnología
Este proyecto está desarrollado con:
* **Frontend:** HTML5, CSS3 (Inter Fonts) y JavaScript.
* **Backend:** [Supabase](https://supabase.com/) para autenticación y base de datos en tiempo real.
* **Geolocalización:** Detección automática de ubicación para segmentación de mercado.

## 🔒 Privacidad y Transparencia
WANTED actúa como un puente tecnológico. La seguridad de los datos y el anonimato de los procesos son nuestra prioridad.
